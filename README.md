# Análisis de Demanda Eléctrica en Argentina — CAMMESA

Proyecto de análisis de datos sobre la demanda eléctrica de Argentina, utilizando información horaria y provincial de CAMMESA para el período 2023–junio de 2026.

El proyecto analiza la evolución y distribución de la demanda eléctrica, sus patrones temporales y provinciales, e incorpora técnicas de clustering y modelos de forecasting para estudiar patrones de consumo y evaluar la capacidad predictiva de distintos enfoques.

**Herramientas utilizadas:** Python · Pandas · NumPy · Scikit-learn · XGBoost · Matplotlib · Power BI
